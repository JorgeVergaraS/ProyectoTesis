Para actualizarlas, iniciar la aplicación local, usar una cuenta de documentación
con datos aptos para publicación, capturar la vista y revisar la imagen completa
antes de versionarla. No incluir mensajes privados, tokens, ventanas de permisos
ni credenciales.
